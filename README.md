# 蓝牙同步 · 远程工作台

DEMO / dmeo v0.3.6-dev，2026-11-15。GitHub Pages 静态网页，通过 WSS 直连私有 MQTT；无需另租服务器。

这是公开的网页程序，不包含设备密码、真实配对前缀、设备资料或云平台管理员密钥。登录页可以公开访问，设备数据和控制权限由 MQTT 账号及 ACL 保护。请使用单独创建的受限网页账号，不要使用设备账号或云平台 API Key 登录。

登录时填写部署域名、端口8084、主题前缀、主编号和主从本机编号，也可导入自己保存在本机的无密码连接资料。密码只用于当前会话；退出清除页面中的设备数据。浏览器必须支持安全WebSocket和现代JavaScript。

主端省电时，网页显示预计深睡与计划唤醒；操作将在下次联网处理。新权限未配置或设备未烧录时，“尚未上报”是正常状态。页面不会模拟实物在线。

源码支持最多五个北京时间工作时段、主端省电、从端常在线、最近状态/历史、配置版本冲突、独立指令ID与执行回执。固定模式仍保留远程配置和每日校时。v0.3.2取消独立联网批次冷却，保留逐次短退避和单次超时。

主端已完成真实 ML307C 的 SIM 注网、UTC 校时、TLS MQTT、控制订阅和 QoS 1 状态发布；从端已完成 USB/维护网页、WiFi/校时和 MQTT 连接/订阅的局部实机验证。完整主从广播、射频抓包、深睡电流和长期稳定性仍待验收。GitHub Pages在实际使用地区和运营商网络的可访问性需另行验证。

v0.3.4 将网页订阅合并为每台设备一个授权子树及一个 raw 主题，两台设备共三条；支持的八台上限共九条。避免旧版为两台设备创建十三条订阅时出现的部分 SUBACK 拒绝。账号仍须只允许指定设备和指令，不授予全主题权限。

MQTT.js 5.10.4 的来源、完整性信息及MIT许可证见 `vendor/`。网页自身代码尚未另授开源许可证，公开可读取不等于允许任意再分发第三方或设备资料。


v0.3.6增加来自真实设备的SIM/模组、固件版本和配置诊断；诊断有独立更新时间，不能替代最新在线状态。常在线状态心跳改为60秒，150秒无有效上报显示未知，降低100MB/月物联网卡的常驻流量。异常时间戳或空MQTT消息不使页面渲染中断。备份与网络凭据仍仅在本地维护后台处理，不经公开网页或MQTT传递。


v0.3.6修复主端存储故障下的关机泵送；在原厂已有独立NVS分区时，主端迁移到独立项目命名空间，保留旧记录与分区表。配置仍可用时，即使其他记录保存失败，仍允许本地认证导出配置。
